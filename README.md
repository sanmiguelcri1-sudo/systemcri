# SYSTEMCRI Intersoftic

Aplicación local enfocada solo en Estadística Intersoftic y Auditoría Intersoftic.

## Usar como programa

1. Ejecutar `build_systemcri_exe.cmd`.
2. Abrir `dist\SYSTEMCRI.exe`.
3. Dejar `dist\.env` junto al ejecutable con los datos reales.

SYSTEMCRI abre una ventana propia de escritorio.
